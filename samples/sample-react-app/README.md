# Headless Form sample React app

This sample renders forms from the Headless Form API. It is built with [Vite](https://vite.dev/).

## Configuration

Set the backend URLs in `.env`. Only variables that start with `REACT_APP_` are exposed to the app.

## Available scripts

Run these commands in this folder, or use the root scripts described in the main README.

### `npm start`

Runs the app in development mode on [http://localhost:3000](http://localhost:3000).
The page reloads when you edit the code.

### `npm run build`

Type-checks the code and builds the app for production into the `build` folder.

### `npm run preview`

Serves the production build locally, so you can check it before deploying.
